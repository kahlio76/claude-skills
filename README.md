# Claude Skills

[Claude Code skills](https://code.claude.com/docs/en/skills) I use to run my day from an Obsidian vault and TickTick.
Copy a folder into `~/.claude/skills/` and replace placeholders like `<your Obsidian vault>` and `<your timezone>`.
They assume connected TickTick and Google Calendar tools, and `/focus` uses Spotify and `terminal-notifier`.

- `/now`: picks one next action from your real deadlines, with guardrails when an exam is close
- `/plan-day`: writes today's plan into the daily note
- `/wrap-day`: summarizes what got done and rolls the rest to tomorrow
- `/clear-tasks`: moves tasks from the daily note into TickTick
- `/process-inbox`: sorts an inbox note into tasks and filed notes
- `/focus`: starts a timer and builds a playlist for a focus block
